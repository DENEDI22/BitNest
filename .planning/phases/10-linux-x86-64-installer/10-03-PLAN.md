      **Step 3.1 — Docker install (if missing):**
      ```python
      if self.config["docker_missing"]:
          log.write(Text.from_ansi("[•] Installing Docker Engine..."))
          info = read_os_release()
          path = get_docker_install_path(info)
          commands = get_docker_install_commands(path)
          for cmd in commands:
              log.write(Text(f"    → Running: {' '.join(cmd)}", style="dim"))
              result = subprocess.run(cmd, capture_output=True, text=True)
              if result.returncode != 0:
                  # show error and abort
                  log.write(Text(f"[✗] Docker installation failed: {result.stderr.strip()}", style="#e17055"))
                  log.write(Text(f"Installation failed: Docker install error. Press Q to quit.", style="#e17055"))
                  return
          log.write(Text("[✔] Docker Engine installed", style="#00b894"))
      ```

      **Step 3.2 — Add user to docker group:**
      ```python
      import os
      username = os.environ.get("USER", os.environ.get("LOGNAME", ""))
      subprocess.run(["sudo", "usermod", "-aG", "docker", username], check=False)
      log.write(Text("[✔] User added to docker group", style="#00b894"))
      ```
      Per D-11: use `sudo docker compose` for all remaining compose calls in this session.

      **Step 3.3 — Create install directory:**
      ```python
      install_dir = Path(self.config["install_dir"])

      log.write(Text(f"[✔] Install directory created: {install_dir}", style="#00b894"))
      ```

      **Step 3.4 — Write compose.yaml:**
      ```python
      compose_content = render_compose(
          api_port=self.config["api_port"],
          frontend_port=self.config["frontend_port"],
      )
      compose_path = install_dir / "compose.yaml"
      compose_path.write_text(compose_content)
      log.write(Text("[✔] compose.yaml written", style="#00b894"))
      ```

      **Step 3.5 — Write .env:**
      ```python
      env_path = install_dir / ".env"
      write_env_file(env_path, self.config)
      log.write(Text("[✔] .env written (chmod 600)", style="#00b894"))
      ```

      **Step 3.6 — Pull images with streaming output:**
      Use `subprocess.Popen` per Pattern 2 from RESEARCH.md. Command: `["sudo", "docker", "compose", "-f", str(compose_path), "pull"]`. Stream each stdout line to RichLog. Show animated `[•]` prefix via periodic update. Per D-24: never shell=True, never cwd=.
      ```python
      log.write(Text("[•] Pulling images...", style="#fdcb6e"))
      cmd = ["sudo", "docker", "compose", "-f", str(compose_path), "pull"]
      with subprocess.Popen(cmd, stdout=subprocess.PIPE, stderr=subprocess.STDOUT, text=True) as proc:
          for line in proc.stdout:
              stripped = line.rstrip()
              if stripped:
                  log.write(Text(f"    → {stripped}", style="dim"))
      if proc.returncode != 0:
          log.write(Text("[✗] Image pull failed. Press Q to quit.", style="#e17055"))
          return
      log.write(Text("[✔] Images pulled", style="#00b894"))
      ```

      **Step 3.7 — Start stack:**
      ```python
      subprocess.run(["sudo", "docker", "compose", "-f", str(compose_path), "up", "-d"], check=True)
      log.write(Text("[✔] Stack started", style="#00b894"))
      ```

      **Step 3.8 — Health poll:**
      ```python
      log.write(Text("[•] Waiting for services to become healthy...", style="#fdcb6e"))
      health = poll_health(str(compose_path), timeout=60, use_sudo=True)
      for svc, ok in sorted(health.items()):
          icon = "[✔]" if ok else "[✗]"
          color = "#00b894" if ok else "#e17055"
          log.write(Text(f"    {svc:12s} {icon} {'healthy' if ok else 'unhealthy'}", style=color))

      if all(health.values()):
          # Write state file
          write_state(
              install_dir=str(install_dir),
              api_port=self.config["api_port"],
              frontend_port=self.config["frontend_port"],
              compose_file=str(compose_path),
          )
          # Auto-advance to Step 4
          self.app.call_from_thread(
              self.app.push_screen,
              Step4DoneScreen(self.config)
          )
      else:
          log.write(Text("[✗] Some services failed to start. Press Q to quit.", style="#e17055"))
      ```
