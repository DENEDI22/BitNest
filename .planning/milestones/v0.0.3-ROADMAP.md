## Milestone Summary

**Key Decisions:**
- PBKDF2-SHA256 with versioned hash payload (`v1.iterations.salt.hash`) for password storage
- JWT bearer access tokens (15 min) + hashed opaque refresh secrets in RefreshSessions table
- File grants modeled as dedicated FileGrant entity with unique index on (FileId, GrantedUserId)
- Sharepoint tokens stored as SHA256 hash (raw token never persisted); Cascade on File delete
- Upload slot validation via IsValid/IsSlotFull discriminated union at API boundary
- Installer requires `sudo` at startup; internal `sudo` prefixes retained for individual commands
- Textual TUI with @work decorators (thread=True) for async prerequisite checks
