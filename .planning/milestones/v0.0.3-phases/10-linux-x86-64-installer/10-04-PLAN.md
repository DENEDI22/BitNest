  <what-built>
    Complete BitNest Linux x86_64 installer — a single Python script with Textual TUI that:
    - Shows main menu with Install/Update/Uninstall options
    - Runs prerequisite checks (Docker, Compose V2, ports, disk space)
    - Collects configuration with inline validation
    - Installs Docker if missing, creates compose stack, pulls images, starts services
    - Shows live progress with pass/fail per service
    - Supports update flow (pull + restart) and uninstall flow (two confirmations)
    - Seeds admin account via API env vars
  </what-built>
  <how-to-verify>
    **Prerequisites:** Ensure Docker is available. If testing Docker auto-install, use a VM without Docker.

    **Test 1 — Fresh install flow:**
    1. Remove any prior state: `rm -f ~/.config/bitnest/install.json`
    2. Run: `python3 installers/linux-x86_64/install.py`
    3. Verify: Main menu shows with "Install BitNest" pre-highlighted
    4. Press Enter to select Install
    5. Verify: Step 1 shows prerequisite checks with pass/fail icons and correct colors
    6. Press "Next Step"
    7. Verify: Step 2 shows 5 input fields with defaults (~/bitnest, 5000, 3000)
    8. Enter admin username (min 3 chars) and password (min 8 chars)
    9. Test validation: try empty username, verify error appears below field
    10. Press "Next Step" with valid values
    11. Verify: Step 3 streams install progress with live status lines
    12. Verify: Images pull with streaming output visible in RichLog
    13. Verify: Health poll shows per-service pass/fail
    14. Verify: Step 4 success screen shows URLs and admin username (NOT password)
    15. Open browser to http://localhost:3000 — verify BitNest loads
    16. Log in with the admin credentials you provided — verify access works

    **Test 2 — Update flow:**
    1. Re-run: `python3 installers/linux-x86_64/install.py`
    2. Verify: Main menu pre-highlights "Update BitNest" (state file exists)
    3. Select "Update BitNest"
    4. Verify: Shows installed path and timestamp from state file
    5. Press "Update BitNest"
    6. Verify: Pull output streams, stack restarts, health poll shows results
    7. Verify: No "docker compose down" — services stay up during pull

    **Test 3 — Uninstall flow:**
    1. Re-run installer, select "Uninstall BitNest"
    2. Verify: First confirm shows install directory and "Continue?" prompt
    3. Press "Continue to Uninstall"
    4. Verify: Second confirm shows red warning "Delete all data?" with destructive styling
    5. Press "Keep My Data" — verify stack stops but data directory preserved
    6. OR: Press "Delete Everything" — verify data directory deleted, state file deleted

    **Test 4 — Navigation:**
    1. Start installer, go to Step 1, press Back — verify returns to main menu
    2. Go to Step 1, Next to Step 2, press Back — verify returns to Step 1
    3. Press Q at any point — verify app exits cleanly
